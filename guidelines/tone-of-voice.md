# AFLUENCE — Tone of Voice Guide

## Definition

**Provocador + Aspiracional** (60/40)

> "We challenge what's broken. We build what's next."

Provocar para despertar. Elevar para construir.

## Formula

Challenge the present → Elevate toward the future

## Signature phrases

- "Your course has 12% completion. Your empire deserves better."
- "Everyone sells followers. We build infrastructure."
- "PDFs die in a folder. Empires don't."
- "Not a guru. Not an agency. An AI Factory."
- "We don't pitch ideas. We build empires."
- "From audience to asset. From content to company."

## DO's

- Usa datos y numeros concretos para provocar (12% vs 90%)
- Nombra lo que esta roto sin miedo
- Conecta cada provocacion con una vision de imperio
- Frases cortas. Parrafos cortos. Ritmo rapido.
- Habla como builder, no como vendedor
- Usa contraste: lo viejo vs lo nuevo
- Cierra con poder: la ultima frase siempre es la mas fuerte

## DON'Ts

- Nunca suena a guru o coach motivacional
- Nunca usa exclamaciones exageradas (!!!) o emojis excesivos
- Nunca promete sin sustancia ("gana millones facil")
- Nunca habla mal de personas, solo de sistemas rotos
- Nunca suena desesperado o suplicante
- Nunca usa jerga corporativa vacia ("sinergia", "paradigma")
- Nunca se disculpa por ser directo

## Words we USE

Construir, Imperio, Ecosistema, Infraestructura, Escalar, Automatizar, Factory, Motor de ventas, IA, Producto inteligente, Builder, Arquitectura, Sistema, Data, Resultado, Co-crear

## Words we DON'T use

Curso, Mentoria tradicional, PDF, Ebook, Webinar, Guru, Coach, Hack, Truco, Secreto, Formula magica, Viral, Contenido organico, Emprendedor, Solopreneur, Hustle

## Tone by channel

| Channel | Style |
|---------|-------|
| Web hero | Bold headline + data-backed subheadline |
| Instagram | Provocative hook → insight → CTA |
| Email subject | Curiosity + challenge ("Tu negocio merece mas que un PDF") |
| Pitch | Data-driven opening → vision → proof |
| WhatsApp/DM | Direct question → value prop → conversation |
