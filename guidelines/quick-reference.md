# AFLUENCE — Quick Reference (Cheat Sheet)

## Colors

| Name | HEX | When to use |
|------|------|-------------|
| Obsidian | `#000000` | Fondos dark (default) |
| Abyss | `#0A0A0A` | Cards, superficies elevadas |
| Slate | `#404040` | Texto secundario, bordes |
| Steel | `#E5E7EB` | Fondos light, dividers |
| Blanco | `#FFFFFF` | Texto principal sobre dark |

**Rule:** Sin colores de acento. Solo escala de grises.

---

## Typography

| Element | Font | Weight | Style |
|---------|------|--------|-------|
| H1 | Sora | Bold (700) | UPPERCASE |
| H2 | Sora | SemiBold (600) | Normal |
| H3 | Sora | Medium (500) | Normal |
| Body | Archivo | Regular (400) | Normal |
| Caption | Archivo | Regular (400) | Color Slate |
| Emphasis | Archivo | SemiBold (600) | Normal |

**Google Fonts import:**
```
Sora:wght@500;600;700;800
Archivo:wght@400;500;600
```

## Logo — Quick Pick

| Need | Use | File prefix |
|------|-----|-------------|
| Presentacion formal | Primary | `afluence-primary-*` |
| Header de email | Compact | `afluence-compact-*` |
| Avatar / favicon | Icon Only | `afluence-icon-only-*` |
| Mencion en texto | Wordmark Only | `afluence-wordmark-only-*` |

| Background | Logo variant |
|-------------|-------------|
| Blanco/claro | `*-black-on-white.*` |
| Negro/oscuro | `*-white-on-black.*` |
| Watermark/sutil | `*-gray.*` |

## Voice — Quick Rules

**Be:** Directo, provocador con datos, builder mindset
**Don't be:** Guru, coach motivacional, corporativo vacio

**Formula:** Challenge what's broken → Build what's next

**Close strong.** La ultima frase siempre es la mas poderosa.
